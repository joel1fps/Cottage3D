# Cottage 3D — versão 1.0.9

- Novos produtos: chaveiro Mario e chaveiro camisa do Brasil.
- Nova foto na galeria do chaveiro colete refletivo.
- Abertura única com fundo bege militar, linha vertical e revelação lateral.
- Botão de adicionar ao orçamento com cantos retos, confirmação, contador e miniatura voando até a sacola.
- Respeito à preferência de movimento reduzido.

O código-fonte está em src/. A pasta dist/ contém o site compilado.
Para desenvolver: npm install e npm run dev. Para compilar: npm run build.
A hospedagem deve redirecionar rotas do site para index.html (SPA).

Verificado em 390 px e 1440 px: abertura, adição repetida, contagem, galeria, movimento reduzido e ausência de rolagem horizontal.
